## 이번 버전에서 바뀐 것 (v0.29.0 → v0.30.0)

**첫 실행에 데이터베이스 마이그레이션 `0013`·`0014`가 한 번씩 돕니다.** `0013`은 정기 실행 표 둘을, `0014`는 그림 표 하나를 새로 만듭니다.
기존 데이터는 건드리지 않습니다. Windows·Linux 판이 같습니다.

### 지시를 등록해 두면 정해진 주기마다 agent가 저절로 돕니다 — 정기 실행

- 사이드바의 리포트 아래에 **`정기 실행`** 이 생겼습니다. workspace별로 묶인 목록, 편집 칸, 실행 기록이 한 화면에 있습니다.
- 등록할 때 정하는 것은 실행 패널과 같습니다(workspace · repo · agent · 모델 · effort · 권한 · 지시 · 맥락). 여기에 두 가지를 더 정합니다.
  - **주기**: `평일` · `매일` · `매주` · `N시간마다` 중에서 고르거나 cron(5필드)을 직접 씁니다. 가장 짧은 간격은 10분이고, 시간대는
    등록할 때의 것을 따릅니다.
  - **대화 방식**: `매번 새 대화`와 `한 대화를 이어 감` 중에서 고릅니다.
- **앱이 켜져 있을 때만 돕니다.** 앱이 꺼져 있는 동안 놓친 회차는 몇 번이든 다음에 켤 때 한 번만 돕니다. 절전에서 깨면 곧바로 확인합니다.
- 실행 기록에는 회차마다 시각과 사유(`정시` · `놓쳐서 실행` · `지금 실행`), 결과, `대화 열기`가 남습니다. `지금 실행`은 정해진 회차와
  상관없이 바로 한 번 돌립니다.
- 다음 경우에는 그 회차를 건너뛰고, 건너뛴 이유를 기록에 남깁니다.
  - 앞 실행이 아직 돌고 있을 때
  - 이어 가는 대화가 답변을 기다리고 있을 때
- 다음 경우에는 저절로 꺼지고, 이유가 목록 줄에 남습니다.
  - **3번 연속 실패했을 때**
  - **repo가 지워졌을 때**
- 한 회차는 60분이 지나면 실패로 끝납니다.
- 정기 실행이 낸 대화도 평소처럼 인박스에 오릅니다.

### repo마다 그림을 그립니다 (Excalidraw)

- 제목 줄의 **`그림`** 버튼(터미널 왼쪽)을 누르면 코드 칸이 그 repo의 그림판이 됩니다.
- 칸 위쪽에서 할 수 있는 일:
  - `그림 고르기` 메뉴로 그림을 고릅니다.
  - `새 그림`(＋)으로 새 그림을 만듭니다.
  - 이름을 바꾸거나 지웁니다(지우기는 두 번 누릅니다).
  - `그림 새 창으로 열기`로 그 그림을 별도 창에서 크게 엽니다.
- **그리는 대로 자동으로 저장합니다.** 칸과 새 창에 같은 그림을 열어 양쪽에서 그려도 합쳐지고, 한쪽에서 지운 것이 다른 쪽에서 되살아나지
  않습니다.
- 한글도 손글씨 글꼴로 그려집니다. 글꼴을 앱에 넣었기 때문에 인터넷이 없어도 됩니다. 그만큼 앱 크기가 약 14 MB 늘었습니다.
- **repo를 지우면 그 repo의 그림도 함께 지워집니다.** 이슈·메모와 다른 점이라, 사이드바의 삭제 확인 글이 `그림 N개도 지워집니다 · 정말
  삭제?`로 바뀝니다.
- 이번에는 넣지 않은 것: 이미지 넣기, 파일로 내보내기, Excalidraw 라이브러리, 웹 임베드.
- 그림은 앱 안에만 저장됩니다. agent는 그림을 볼 수 없습니다.

### 사이드바 하단에서 에이전트 현황을 봅니다

- 사이드바 하단의 MCP 줄이 버튼으로 바뀌었습니다. 이 줄에 실행 중인 수와 대기 수(`실행 1/3 +2 대기`)가 함께 보입니다.
- 누르면 패널이 열리고, 네 가지를 한곳에서 봅니다.
  - 지금 도는 것
  - 에이전트 설치 상태(설정 실행 탭과 같습니다)
  - 지금 workspace의 실행 기본값
  - 설정 파일 — 누르면 그 파일을 기본 앱으로 엽니다
