## 이번 버전에서 바뀐 것 (v0.24.0 → v0.25.0)

데이터베이스 마이그레이션은 없습니다.

### 새 기능

- **사이드바 최소화.** 창 맨 위 제목 줄의 왼쪽 끝 아이콘(`사이드바 최소화`)을 누르면 왼쪽 사이드바가 아이콘 줄로 접힙니다.
  - 접혀도 인박스·리포트·설정 아이콘과 MCP 상태 점은 남습니다. 인박스 건수 배지도 아이콘 위에 그대로 보입니다.
  - workspace 목록은 접힌 동안 보이지 않습니다 — workspace를 바꾸려면 같은 자리의 `사이드바 복원`으로 펼칩니다.
  - 접은 상태는 앱을 다시 켜도 기억합니다.
- **터미널에서 고른 글을 대화에 붙이기.** 터미널 칸에서 글을 드래그해 고른 뒤 칸 머리의 `대화에 붙이기`를 누르면, 그 글이
  코드 블록으로 감싸져 지금 보고 있는 대화의 입력칸 끝에 붙습니다.
  - 쓰던 지시가 있으면 그 뒤에 빈 줄 하나를 두고 붙습니다. 보내지는 않습니다 — 지시를 덧붙여 직접 보내세요.
  - 대화창이 접혀 있으면 펼쳐집니다.
