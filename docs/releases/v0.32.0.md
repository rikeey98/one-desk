## 이번 버전에서 바뀐 것 (v0.31.0 → v0.32.0)

데이터베이스 마이그레이션은 없습니다. Windows·Linux 판이 같습니다.

### 대화에 담는 버튼이 줄 끝으로 옮겨 갔습니다

- 이슈·메모·스킬 줄 맨 앞의 빈 동그라미가 줄 끝의 **`＋ 담기`** 로 바뀌었습니다. 담은 줄은 `✓ 담김`입니다. 담은 줄의 파란 체크가 이슈 완료로
  읽히던 문제가 사라집니다.
- 항목을 열어 둔 채로 패널 머리의 **`＋ 대화에 담기`** 로 담고 뺍니다. 상세를 닫지 않아도 됩니다.

### 이슈에서 시작한 대화가 그 이슈의 repo에서 돕니다

- 이슈를 할당하거나 이슈 하나만 담고 새 대화를 시작하면, 그 이슈에 붙은 repo가 하나일 때 그 repo가 작업 디렉토리가 됩니다. 전에는 사이드바에서
  고른 repo나 첫 repo에서 돌았습니다.
- 이슈의 repo와 작업 디렉토리가 다르면 입력칸 위에 안내와 `<repo>에서 시작` 버튼이 뜹니다. 보내는 것은 막지 않습니다.

### 키보드와 큰 배율에서 쓰기 편해졌습니다

- 터미널 칸에서 **`Ctrl+Shift+Tab`** 을 누르면 셸을 빠져나와 탭 줄로 갑니다. 전에는 Tab을 셸이 받아 키보드로는 나올 수 없었습니다. `?` 단축키
  목록에도 있습니다.
- 대화창 위 경계를 Tab으로 고른 뒤 ↑↓로 높이를 바꿉니다.
- 창이 낮거나 200%로 확대해도 위의 이슈·메모 패널이 사라지지 않습니다. 대화창은 보이는 높이만 줄이고, 창을 되돌리면 끌어 둔 높이로 돌아옵니다.
- 포커스 링이 진한 파랑이 되어 흰 바탕에서도 잘 보입니다. 입력 칸 테두리도 진해졌습니다.
- 대화 목록의 상태 점이 색뿐 아니라 모양으로도 갈립니다. 완료는 원, 실행 중은 고리, 대기는 막대, 실패·중단은 마름모, 취소는 네모, 답변 필요는
  세모입니다.
- 화면 읽기 프로그램이 홈 카드·실행 슬롯·인박스 묶음의 개수와 삭제 확인의 대상을 읽습니다.

### 고친 것

- 긴 메모·이슈·스킬 상세를 스크롤하면 바닥의 `삭제` 띠 아래로 본문이 비치던 것을 고쳤습니다.
- 없는 폴더를 repo로 등록하면 그 자리에서 `존재하지 않는 경로입니다`라고 알립니다. 등록한 뒤 폴더가 사라지면 실행 실패 이유가
  `작업 디렉토리가 없습니다`로 나옵니다. WSL 경로는 등록할 때 확인하지 않습니다.
- 정기 실행 목록과 실행 기록을 읽지 못하면 `다시 시도` 버튼이 뜹니다.
- workspace를 지우면 그 실행 로그 폴더도 지웁니다. 전에는 agent가 읽은 파일 원문이 든 로그가 남았습니다.
- 입력 칸 안내 글자와 경고 배지 글자를 더 진하게 했습니다. 펼침 꺾쇠는 더 이상 돌며 움직이지 않습니다.
