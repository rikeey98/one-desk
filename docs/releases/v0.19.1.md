## 이번 버전에서 바뀐 것 (v0.19.0 → v0.19.1)

데이터베이스 마이그레이션은 없습니다.

### 새 기능

- **별도 창의 목록을 숨기고 폭을 바꿉니다.** "새 창으로 열기"로 연 이슈·메모·skill 창에서:
  - 패널 헤더 오른쪽의 `목록 숨기기` 버튼으로 목록을 숨기면 상세가 창을 다 씁니다. 다시 누르면(`목록 보이기`) 목록이
    그대로 돌아옵니다 — 추가 칸에 치던 글자도 남습니다.
  - 목록과 상세 사이의 경계를 마우스로 끌어 목록 폭을 바꿉니다(200px ~ 창 폭의 60%). 경계를 두 번 누르면 기본 폭으로
    돌아가고, 경계에 포커스가 있으면 ← → 키로도 바꿀 수 있습니다.
  - 폭과 숨김은 창 종류마다 이 PC에 기억됩니다.
- **agent가 대화의 턴마다 시각을 받습니다.** 새 MCP 도구 `get_conversation`이 대화 하나의 턴을 오래된 순으로 주고,
  턴마다 지시를 보낸 때·실행이 시작된 때·끝난 때와 기다린 시간·걸린 시간(초), 상태, 지시와 답의 앞부분을 줍니다.
  "이번 주 대화를 턴별로 언제 시켰고 얼마나 걸렸는지 정리해 줘"처럼 시킬 수 있습니다. 읽기 전용 권한에서도 됩니다.

### 바뀐 것

- **`새 대화` 버튼이 잘 보입니다.** 대화 목록 맨 위의 `새 대화`가 전송 버튼과 같은 파란 버튼이 됐고 글자가 커졌습니다.
  목록을 내려도 맨 위에 고정돼 있고, 새 대화를 쓰는 중이면 바깥 고리로 표시됩니다. 예전에는 작은 점선 버튼이라 찾기
  어려웠습니다.
