## 이번 버전에서 바뀐 것 (v0.25.1 → v0.26.0)

데이터베이스 마이그레이션은 없습니다.

### WSL repo를 등록하면서 한 번에

- **등록 폼에 `WSL` 버튼이 생겼습니다.** 사이드바의 `repo 등록`에서 폴더 버튼 옆의 `WSL`을 누르면, Windows 폴더 창이 WSL 기본
  배포판의 홈 폴더(`Linux › Ubuntu-24.04 › home › <사용자>`)에서 바로 열립니다. 폴더 창의 탐색 창에 `Linux`가 보이지 않는 PC에서도
  됩니다. 배포판이 여럿이면(Docker Desktop을 쓰면 `docker-desktop`이 따로 생깁니다) 기본 배포판에서 열리고, 다른 배포판은 폴더 창
  주소줄의 `Linux`를 눌러 갑니다.
- **WSL 폴더를 고르면 `WSL 안의 claude로 실행`이 켜진 채 나타납니다.** 그대로 `추가`하면 WSL repo로 등록됩니다 — 예전처럼 등록한 뒤
  설정 → repo 탭에서 실행 환경을 바꾸지 않아도 됩니다. 경로를 직접 붙여 넣어도 같습니다. 그 폴더를 Windows의 claude로 돌리려면
  체크를 끄면 됩니다.
- **사이드바에서 WSL repo 이름 옆에 `WSL` 표시가 붙습니다.** 마우스를 올리면 배포판과 Linux 경로가 보입니다.

### 설정에 `WSL` 탭

Windows에서는 설정 화면에 `WSL` 탭이 생겼습니다(실행 · 앱 · repo · **WSL** · 정보). 여기저기 흩어져 있던 WSL 설정을 한곳에 모았습니다.

- **배포판** — 설치된 배포판과 기본 배포판. 배포판이 없으면 설치 방법(`wsl --install`)을 알려 줍니다.
- **WSL 안의 claude** — 실행 파일 · 로그인 · 모델. 실행 탭의 CLI 상태와 같은 판정입니다. WSL repo가 하나 이상 있어야 확인합니다(설정을
  열 때마다 WSL을 깨우지 않으려고 그렇게 했습니다).
- **WSL claude 경로 · WSL 글로벌 skill 경로** — 앱 탭에서 이 탭으로 옮겼습니다. 저장해 둔 값은 그대로입니다.
- **WSL repo** — 지금 고른 workspace에서 WSL로 도는 repo. WSL 폴더인데 Windows의 claude로 도는 repo는 따로 표시하고, `repo 탭에서
  열기`로 바로 고치러 갈 수 있습니다.
- 맨 위의 `다시 확인`은 배포판 목록과 claude 상태를 다시 확인합니다 — WSL을 설치하거나 WSL 안에서 로그인한 뒤 앱을 다시 켜지 않아도
  됩니다.

### 그 밖에

- 설정 화면의 안내문이 한국어 낱말 가운데서 줄바꿈되던 것(`로그` / `인`)을 고쳤습니다.
