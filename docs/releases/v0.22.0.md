## 이번 버전에서 바뀐 것 (v0.21.1 → v0.22.0)

데이터베이스 마이그레이션은 없습니다.

### 새 기능

- **대화 목록이 repo별로 나뉩니다.** 도크의 대화 목록이 대화를 나눈 repo마다 구획으로 묶입니다.
  - 가장 최근에 대화한 repo가 위에 오고, 구획 안도 최신순입니다. 등록하지 않은 경로에서 나눈 대화는 맨 아래 `기타`에 모입니다.
  - 구획 머리를 누르면 접고 펼칩니다. 접어 둔 구획은 앱을 다시 켜도 기억하고, 접힌 구획 안에 실행 중이거나 답변을 기다리는
    대화가 있으면 머리에 표시가 남습니다. 인박스·이슈·리포트에서 "대화 열기"로 연 대화가 접힌 구획 안에 있으면 그 구획만
    펼쳐집니다.
  - 같은 이슈의 대화를 한 줄로 접는 것은 구획 안에서 그대로 됩니다.
  - repo가 하나뿐이면 구획 없이 예전 목록 그대로입니다.
- **사이드바에서 repo를 고르면 도크도 그 repo의 대화만 보입니다** — 이슈·메모 패널처럼. 목록 맨 위의 `api 대화만` 알약에 있는
  ✕를 누르면 거름이 풀립니다(이슈·메모 패널의 거름도 같이 풀립니다). 거름은 목록만 바꿉니다 — 보고 있던 대화는 다른 repo의
  것이어도 그대로 열려 있습니다.

### 알아 둘 것

- 대화가 어느 repo의 것인지는 첫 턴의 작업 디렉토리로 정합니다. 설정에서 repo 경로를 바꾸면 그 전에 나눈 대화는 `기타`로 갑니다.
- 대화 줄과 헤더의 repo 이름도 같은 기준이 됐습니다. 경로 끝의 `\`나 Windows 경로의 대소문자 차이로 repo 이름 대신 폴더
  이름이 보이던 대화가 이제 repo 이름으로 보입니다.
