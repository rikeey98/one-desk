## 이번 버전에서 바뀐 것 (v0.30.0 → v0.31.0)

**첫 실행에 데이터베이스 마이그레이션 `0015`가 한 번 돕니다.** workspace 표에 칸 하나를 더합니다. 기존 데이터는 건드리지 않습니다.
Windows·Linux 판이 같습니다.

### 홈에서 repo를 고르지 않고 agent에게 묻습니다 — 홈 대화

- 홈 화면 바닥에 **`홈 대화`** 가 생겼습니다. 접힌 채 시작하고, 펼친 상태는 이 장비에 남습니다.
- 작업 디렉토리를 고르지 않습니다. agent가 **모든 workspace의 이슈·메모·대화를 읽어** 답합니다. "이번 주에 뭘 했지", "멈춰 있는 일이
  뭐지" 같은 질문을 workspace마다 나눠 묻지 않아도 됩니다.
- **읽기 전용입니다.** 권한이 `읽기 전용`에 고정되어 있고, 이슈·메모를 만들거나 고치는 도구가 없습니다.
- 홈 대화는 인박스와 오늘 할 일에 `홈`으로 뜹니다. `대화 열기`·`답하기`·`다시 보내기`는 홈 화면의 대화 칸으로 데려갑니다.
- 맥락 담기와 이슈 할당은 없습니다. agent가 직접 찾아 읽기 때문입니다.
- 답을 메모로 저장하는 버튼은 아직 없습니다. 답은 대화록과 `응답 복사`로 가져갑니다.

### 홈의 새 대화 카드가 없어졌습니다

- 홈에서 고른 workspace · repo로 보내던 카드를 뺐습니다. 홈에서 보내는 대화는 이제 `홈 대화` 하나입니다.
- 특정 repo에서 agent를 돌리려면 그 workspace 화면의 대화 칸을 씁니다.
- 처음 켰을 때의 준비 단계는 그대로입니다.

### 리포트에서도 홈 대화를 씁니다

- 리포트 화면 바닥에 같은 `홈 대화`가 붙었습니다. 리포트를 보면서 물어볼 수 있습니다.
- **`agent에게 다듬기`가 바뀌었습니다.** 메모를 만들지 않고 workspace로 옮겨 가지도 않습니다. 지시와 지금 보이는 리포트를 홈 대화의 입력칸에
  채웁니다. 보내지는 않으니 읽고 고쳐서 보내면 됩니다.
- `<workspace>에 메모로 저장`은 그대로입니다.

### 사이드바 하단 줄이 간략해졌습니다

- 하단 줄이 `● Claude Code  ● OpenCode        ● MCP`처럼 **쓸 수 있는 agent와 MCP 상태**를 보입니다. WSL의 claude는 `Claude Code (WSL)`이고,
  쓸 수 있는 agent가 없으면 `agent 없음`입니다.
- 포트, 실행 수, 대기 수는 줄에 마우스를 올리면 풍선으로 보입니다. 누르면 에이전트 현황 패널이 열리는 것은 그대로입니다.

### 고친 것

- 로그아웃한 Claude Code가 CLI 상태에 `인증 확인 불가 (종료 코드 1)`로 보이던 것을 `로그인 필요`로 고쳤습니다. 이제 칠 명령(`claude auth login`)을
  알려 줍니다.
