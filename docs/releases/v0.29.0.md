## 이번 버전에서 바뀐 것 (v0.28.0 → v0.29.0)

**첫 실행에 데이터베이스 마이그레이션 `0012`가 한 번 돕니다** — 이슈 제안을 담는 표 하나를 새로 만들 뿐이고 기존 데이터는 건드리지 않습니다.
Windows·Linux 판이 같습니다.

### 터미널을 여러 개 열고, 열 때 셸을 고릅니다

- 터미널 칸 머리에 **탭 줄**이 섭니다. repo마다 탭을 8개까지 열 수 있고, 탭은 보이지 않는 동안에도 돕니다 — 다른 탭·다른 repo·인박스에
  다녀와도 출력이 그대로입니다.
- `새 터미널`(＋)은 기본 셸(설정 앱 탭의 `터미널 셸`)로 새 탭을 엽니다. 옆의 `셸 고르기`(▾)에서 셸을 고릅니다 — Windows는
  PowerShell 7 · Windows PowerShell · **명령 프롬프트(cmd)** · Git Bash 중 그 장비에 있는 것만 나옵니다. WSL repo는 그 배포판의 셸입니다.
- 탭 이름은 셸 이름이고 같은 셸이 둘이면 번호가 붙습니다(`pwsh 2`). 도는 탭의 닫기는 두 번 누릅니다(`정말 닫기`).
- 탭을 닫으면 그 탭이 띄운 프로세스까지 끝나고, 앱을 끄면 모든 탭이 끝납니다. 탭이 스스로 끝나면 그 자리의 `다시 시작`으로 다시 띄웁니다.

### agent가 대화를 이슈로 만들자고 제안합니다 — 사람은 한 번 누릅니다

- 이슈가 없는 대화에서 agent가 "이건 할 일이다"라고 판단하면, 대화록과 입력칸 사이에 **`이 대화를 이슈로 만들까요?`** 가 뜹니다.
  제목을 고쳐 `이슈로 만들기`를 누르면 이슈가 생기고 그 대화에 할당됩니다.
- 비슷한 이슈가 이미 있으면 **`기존 이슈 「…」에 붙일까요?`** 로 뜹니다(완료된 이슈에는 붙이지 않습니다).
- `이슈로 만들지 않기`를 누르면 그 대화에는 다시 제안하지 않습니다. 기다리는 제안이 있는 동안은 새 제안을 받지 않습니다 — 고치던 배너가
  바뀌지 않습니다.
- 단순한 질문에는 뜨지 않게 안내했습니다(진짜 claude로 질문 6번 중 0번, 할 일 지시 6번 중 4번 떴습니다).

### 권한

- **읽기 전용의 뜻이 "앱 데이터(이슈·메모·대화)와 파일을 바꾸는 도구가 없다"로 바뀌었습니다.** 읽기 전용 실행에도 MCP 도구
  `propose_issue`(제안만 저장합니다 — 받는 것은 사람의 버튼)가 섭니다.
- **OpenCode의 읽기 전용·편집 허용에서 one-desk MCP 도구가 열렸습니다.** 전에는 그 두 권한에서 OpenCode가 `list_issues`조차 못 썼습니다.
  다른 MCP 서버와 셸 명령은 그대로 막혀 있습니다.
