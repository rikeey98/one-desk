## 이번 버전에서 바뀐 것 (v0.16.0 → v0.17.0)

**마이그레이션 없음** — 기존 데이터 그대로 열립니다.

### 새 기능

- **`@`로 파일 참조** — 입력칸에서 `@`를 치면 작업 디렉토리 repo의 파일을 검색해 고를 수 있습니다
  (Claude Code·OpenCode 모두). 고르면 `@경로`가 입력되고, 보낼 때 앱이 그 파일을 읽어 맥락으로 함께
  보냅니다. 대화 헤더의 "담긴 것"에 `파일 · 경로`로 보입니다.
  - git 저장소인 repo에서만 동작하며, `.gitignore`로 무시된 파일은 목록에 없습니다.
  - repo 밖·바이너리·UTF-8이 아닌 파일이거나, 파일당 256 KiB·한 번에 512 KiB·20개를 넘으면 보내기 전에
    막고 이유를 알려줍니다.
- **↑로 이전 지시 불러오기** — 입력칸이 비어 있을 때 ↑/↓로 이 대화에서 보낸 지시를 차례로 불러옵니다.
  불러온 글을 고치기 시작하면 그때부터는 일반 줄 이동입니다. 새 대화 칸에는 불러올 지시가 없습니다.
- **Claude 요금제 사용률 표시** — 사이드바 맨 아래 MCP 줄 밑에 `요금제 5h 6% · 7d 2%`처럼 5시간·7일
  한도 사용률이 보입니다. 마우스를 올리면 각 한도의 리셋 시각과 마지막 확인 시각이 나옵니다.
  80%를 넘거나 한도에 막히면 경고색이고, 리셋 시각이 지난 한도는 `—`로 보입니다.
  - Claude Code 실행이 한 번 있어야 값이 생깁니다(앱을 켠 직후에는 줄이 없습니다).
  - Pro/Max 구독으로 로그인했을 때만 나옵니다 — AWS Bedrock·API 키 환경에서는 표시되지 않습니다.
  - 값은 앱 메모리에만 두고 DB·로그 파일에 저장하지 않습니다. 크레딧·초과 사용 상태는 읽지 않습니다.

### 고친 것

- **컨텍스트 링이 턴마다 100% 가까이 튀었다 떨어지던 문제** — CLI가 요청별 사용량을 주지 않는 턴에서
  턴 전체의 합계로 점유를 계산해, 도구를 많이 쓴 턴마다 `>99%`가 나왔습니다. 이제 그런 턴은 앞 턴의
  값을 그대로 보입니다. 창 크기도 보조 모델이 아니라 대화를 실제로 처리한 모델 기준으로 잡습니다.
  이미 저장된 지난 턴의 값은 바뀌지 않습니다.
- **로그인한 뒤에도 슬래시 커맨드 목록이 비어 있던 문제** — 로그인하기 전에 실패한 조회 결과가 수동으로
  새로고침할 때까지 남아 있었습니다. 이제 로그인이 확인되면 목록을 다시 읽습니다. 설정 화면의 `다시 확인`은
  workspace의 모든 repo 커맨드 목록을 새로 읽습니다.
- **skill·agent 폴더 이름을 바꾸면 옛 이름과 새 이름이 두 줄로 남던 문제** — 사라진 파일 중 어떤 실행에도
  담긴 적 없는 것은 목록에서 지웁니다. 지난 실행에 담긴 적 있는 것은 기록을 위해 남기되, 목록 맨 아래 접힌
  `사라진 파일 N` 안에서만 보입니다. repo 폴더 자체가 없을 때(드라이브 분리 등)는 지우지 않습니다.
- **보안 — 맥락 속 `@경로`를 Claude CLI가 파일로 펼치던 문제** — Claude CLI는 프롬프트의 `@경로`를 도구
  권한과 무관하게 읽어 붙이고 repo 밖 경로도 읽습니다. 담은 이슈·메모·skill 본문에 `@경로`가 있으면 그
  파일이 실행에 딸려 갈 수 있었습니다. 이제 맥락 본문과 지시문의 `@`를 CLI가 펼치지 못하는 형태로 바꿔 보냅니다
  (`@`로 고른 파일은 앱이 직접 읽어 따로 싣습니다).
