## 이번 버전에서 바뀐 것 (v0.19.2 → v0.19.3)

데이터베이스 마이그레이션은 없습니다.

### 새 기능

- **CLI 경로를 한 번만 정하면 됩니다.** 설정 → 앱 탭 맨 위에 "CLI 기본 경로"가 생겼습니다. 여기에 Claude Code·OpenCode
  실행 파일을 넣으면 모든 workspace가 그것을 씁니다. 예전에는 workspace마다 따로 넣어야 했습니다.
  - 특정 workspace만 다른 실행 파일을 쓰려면 실행 탭의 "CLI 경로 — 이 workspace만"에 넣으세요. 그쪽이 이깁니다.
  - 실행 탭의 칸을 비워 두면 지금 무엇을 따르는지(`앱 기본값: …` 또는 `PATH에서 찾기`) 안내가 보입니다.
  - 이미 workspace에 넣어 둔 경로는 그대로 남습니다. 지우면 앱 기본값을 따릅니다.

### 고친 것

- **OpenCode 대화에서 권한을 "전체 허용"으로 바꾸면 실패하던 문제.** 편집 허용으로 잘 되던 대화가 전체 허용으로 바꾸는
  순간 `opencode run [message..]` 도움말만 남기고 실패했습니다. OpenCode 1.18.0 전 버전이 모르는 옵션을 붙이고 있었기
  때문입니다. 이제 1.4.0 이상의 모든 OpenCode에서 전체 허용이 됩니다.
- **npm으로 설치한 OpenCode(`npm i -g opencode-ai`)를 못 쓰던 문제.** `opencode.cmd`가 잡히면 자동으로도, 경로를
  직접 넣어도 실행을 거부했습니다. 이제 그 안의 진짜 실행 파일(`node_modules\opencode-ai\bin\opencode.exe`)을 찾아
  씁니다. 아무것도 설정하지 않아도 PATH에서 자동으로 잡힙니다.

### 주의

- **OpenCode 1.4.0 미만은 더 이상 지원하지 않습니다.** 그 버전에서는 실행 전에 "너무 오래됐습니다" 안내가 뜹니다.
  `opencode upgrade` 또는 다시 설치해 올려 주세요.
