## 이번 버전에서 바뀐 것 (v0.32.0 → v0.33.0)

데이터베이스 마이그레이션은 없습니다. Windows·Linux 판이 같습니다.

### 답이 왔는데 "실행 중"인 이유를 보여 줍니다

Claude Code는 agent가 뒤에서 돌려 둔 명령(서버 띄우기, 빌드 등)이 끝날 때까지 실행을 끝내지 않습니다. 그동안 답은 이미 와 있는데 대화가
"실행 중"으로 남고 이유가 화면에 없었습니다.

- 그동안 대화록의 상태 줄이 **`답 도착 · 기다리는 중`** 과 남은 작업(`백그라운드 작업 1개 실행 중 · …`)을 보여 줍니다. 기다리기 싫으면 옆의
  `멈추기`를 누릅니다.
- 작업이 끝나면 agent가 한 번 더 답합니다. `자세히`를 펼치면 작업의 시작과 끝이 줄로 서 있어 왜 답이 두 번 나왔는지 보입니다.
- 기다리는 시간과 동작은 바꾸지 않았습니다. 기다리는 동안 그 대화에 보낸 다음 지시는 지금처럼 앞 실행이 끝난 뒤 시작합니다.
- Claude Code가 작업 목록을 알려 주는 판에서만 보입니다(2.1.312에서 확인). OpenCode에는 해당이 없습니다.

### 좁은 창과 확대한 화면

- 창 폭이 좁으면(900px 아래) 사이드바가 저절로 아이콘 줄로 접힙니다. 넓히면 돌아옵니다.
- 좁은 목록 칸에서 이슈·메모·스킬 줄의 제목이 사라지던 것을 고쳤습니다. 줄 오른쪽 표식이 먼저 접히고 제목이 남습니다.
- 앱 창을 760×500보다 작게 줄일 수 없습니다.
- 상세를 Tab으로 내려갈 때 포커스가 바닥의 `삭제` 띠 밑에 숨지 않습니다.

### 고친 것

- workspace를 지우면 그 workspace에서 돌던 agent와 기다리던 실행을 멈춥니다. 전에는 화면에서 멈출 길이 없는 채로 계속 돌며 실행 슬롯을
  차지했습니다.
- 정기 실행이 60분 시간 초과로 끝날 때 WSL 안의 agent까지 끝냅니다. 전에는 Windows 쪽 프로세스만 끝나고 WSL 안의 agent가 남을 수 있었습니다.
- agent가 오류 출력을 끝없이 쓸 때 앱의 메모리가 따라 늘던 것을 막았습니다.
