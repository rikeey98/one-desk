# Intent: 입력칸에서 ↑로 이전 지시 불러오기

- 출처: `docs/backlog.md` §3 (2026-09-28)
- 작성자: 권용현 (초안: Claude)
- 상태: 결정 반영 (2026-09-28)

## 문제

같은 대화에서 방금 보낸 지시를 조금 고쳐 다시 보내거나, 실패한 턴의 지시를 손봐 보내려면
대화록의 사용자 버블을 찾아 복사해 붙여야 한다. 셸·OpenCode·Claude Code TUI는 입력칸에서
↑만 누르면 된다.

## 원하는 결과

입력칸에서 ↑를 누르면 이 대화에서 보낸 지시가 최근 것부터 차례로 나오고, ↓로 되돌아온다.
가장 최근 것보다 더 ↓하면 빈 입력칸으로 돌아온다.

## 정해진 것 (2026-09-28, 사용자)

- **입력칸이 비었을 때만** ↑가 history다. 쓰던 글이 있으면 ↑는 평소처럼 줄 이동이다.
- **범위는 이 대화의 지시뿐이다.** 새 대화 칸에는 history가 없다.
- 재료는 이미 렌더러에 있다 — 대화의 턴(`Run.userPrompt`). core·IPC·스키마 변경은 없다.

## 제약

- `/` 피커가 열려 있으면 ↑↓는 피커가 가진다(slash-commands).
- IME 조합 중인 키는 건드리지 않는다.
- 초안은 `renderer/store/drafts.ts`가 쥔다(conversation-timeline FR-31).
