# Intent: OpenCode처럼 읽히는 대화 화면

- 작성자: 권용현 (Claude가 초안)
- 상태: 승인 위임됨 (2026-09-27 — 사용자: "추천해준대로 쭉 수행해줘, ui도 비슷하게 바꿔줘")
- 작성일: 2026-09-27
- 선행: `docs/sdlc/conversation-fixes/` (대표 턴·활성 턴·실행 중 취소가 여기서 생긴다)

## 문제

2026-09-27, 사용자가 로컬의 OpenCode Desktop 2.0.18을 기준으로 "대화를 리팩토링하고 UI도
비슷하게" 바꾸길 원했다. 실측(화면 캡처·설치 번들·v2.0.18 소스)과 one-desk 코드 조사로 본
격차는 대부분 **이미 가진 데이터를 화면이 쓰지 않는 것**이다.

- **진행 중에 아무것도 안 보인다.** 대화록 본문은 턴이 끝나야 채워지는 `run.resultText`만
  그린다. 진행 중 턴에는 사용자 버블과 영어 `running` 칩뿐이고, 흐르는 텍스트·도구 호출은
  "자세히"를 펼친 `RunLog`에만 모노스페이스 한 줄씩(`→ Bash`) 나온다. 그런데 text·tool_use
  이벤트는 이미 전역 push로 렌더러 스토어에 와 있다.
- **도구 호출이 이름뿐이다.** `→ 이름 첫경로`. Bash 명령·Grep 패턴·Edit의 old/new가 이벤트의
  `input`에 원본으로 있는데 쓰지 않는다. tool_use와 tool_result를 짝짓지 않는다.
- **답변이 평문이다.** 코드 블록·목록이 안 그려지고 복사 버튼이 없다.
- **입력부가 밀려난다.** 도크 본문 하나가 대화록·맥락 줄·실행 패널을 한 덩어리로 스크롤해,
  대화가 길면 입력창이 아래로 밀린다(DESIGN.md "헤더와 입력부는 밀려나지 않는다" 위반).
  기본 도크 높이(창의 34%)에는 실행 패널조차 다 안 들어간다. 자동 스크롤도 없다.
- **대화에 머리가 없다.** 제목·agent·누적 사용량을 볼 자리가 없고, "대화 끝내기"는 목록 줄
  hover에만 있어 찾기 어렵다(lifecycle plan 남은 일 3번).
- **턴의 실행 조건이 안 보인다.** effort·권한·소요 시간이 대화록에 없다.
- **실패한 턴에서 할 일이 없다.** 같은 대화 안에서 다시 보낼 방법이 없다(인박스의 "다시 실행"은
  새 대화를 만들고 조건을 잃는다).
- **예약이 대화록 안의 버블이다.** OpenCode는 대기 중인 후속 메시지를 입력창 위 칩으로 둔다.

## 원하는 결과

OpenCode Desktop의 세션 화면처럼 읽힌다 — 오른쪽 사용자 버블, 왼쪽 마크다운 답변, 활동은
한 줄 묶음, 답변 아래 `agent · 모델 · 22초` 메타 줄과 복사, 입력창은 바닥에 고정된 카드이고
실행 중엔 전송 버튼이 중지(■)가 된다.

## 결정 (2026-09-27, 사용자 위임으로 Claude가 추천안을 택함)

- **D1 "모든 턴은 접힌 채로 시작"(2026-09-22 사용자 결정)은 유지한다.** 그 결정의 이유는
  "도구 호출이 흐르면 대화록이 그것으로 가득 차 지시와 답변이 밀려난다"였다. 그래서 접힌 턴이
  보여주는 것을 **OpenCode "텍스트만"에 가깝게** 정한다: 사용자 버블, 답변(끝났으면 최종 답,
  진행 중이면 **지금까지의 마지막 텍스트 블록**), 진행 중 상태 줄(작업 중 · 경과 시간 · 지금
  도는 도구), 한 줄 활동 요약("도구 7회"), 메타 줄. **"자세히"를 펼치면 OpenCode "컴팩트"
  타임라인**(중간 텍스트 + "4 읽기, Grep, 셸 사용됨 ▸" 활동 묶음, 묶음을 펼치면 도구별 한 줄,
  셸은 명령·출력, 편집은 diff)이 나온다. 펼치고 접는 것은 여전히 사용자만 한다.
- **D2 마크다운 렌더링을 붙인다.** 대화 설계 2026-08-18 §7이 "마크다운"을 뺐던 것을 이
  요청으로 되살린다. 전제는 CLAUDE.md의 경고 — agent 출력은 신뢰할 수 없는 입력이다:
  **원시 HTML 금지, `dangerouslySetInnerHTML` 금지, 원격 이미지 로드 금지, 앱 안 탐색 금지.**
- **D3 예약(대화당 하나, 설계 §3-2 그대로)을 입력창 위 칩으로 옮긴다.** 대화록에는 턴이
  시작된 뒤에야 나타난다. 칩에서 취소한다. 여러 개 예약은 이 기능이 아니다.
- **D4 입력부는 카드 하나다.** 위는 입력칸, 아래 줄은 작은 알약 선택(agent·모델·effort·권한·
  작업 디렉토리) + 오른쪽 전송 버튼. 대화에 실행 중 턴이 있고 입력이 비었으면 전송 버튼이
  **중지(■)**가 된다. 실행 단축키는 지금(Ctrl/⌘+Enter)을 유지한다.
- **D5 대화 헤더를 둔다.** 제목(누르면 이름 바꾸기), ⋯ 메뉴(이름 바꾸기 · 대화 끝내기),
  agent·repo, 오른쪽에 컨텍스트 링(마지막 턴의 점유 ÷ 창 — CLAUDE.md의 "점유" 정의를 따른다,
  OpenCode 공식을 베끼지 않는다)과 누적 토큰·비용 팝오버. lifecycle 남은 일 3번을 이것으로 푼다.
- **D6 도크를 최대화할 수 있다.** 도크 헤더의 버튼으로 본문 전체 높이를 쓴다(OpenCode의 세션
  화면처럼). 다시 누르거나 Esc로 돌아온다. 기본 도크 높이는 입력부가 들어가게 올린다.
- **D7 스크롤은 대화록만 한다.** 헤더와 입력부는 고정. 바닥에 있으면 새 내용을 따라가고,
  위로 올렸으면 "최신으로" 버튼이 뜬다. 대화를 바꾸면 바닥에서 시작한다.
- **D8 메타 줄**: `agent · 모델 · 소요 시간 · effort · 권한` + 복사. 진행 중엔 시간이 흐른다.
  턴 사이에 모델·effort가 바뀌면 가운데 정렬 공지선("모델 → X")을 넣는다.
- **D9 실패·중단 턴에 "다시 보내기"**: 같은 대화에 같은 지시·맥락·조건으로 새 턴을 잇는다.
  답변 필요 턴은 입력창에 포커스를 준다.
- **D10 대화별 입력 초안을 보존한다.** 대화를 바꾸거나 인박스에 다녀와도 쓰던 지시가 남는다.
- **D11 상태 이름을 한 표로.** 영어 enum이 화면에 나가지 않는다(`permission.ts`처럼 공유).
  대화 영역의 `opacity` 흐림과 유니코드 글리프를 토큰·SVG 아이콘으로 바꾼다.

## 영향 범위

- renderer: `Dock.tsx`, `ConversationList.tsx`, `ConversationPanel.tsx`, `Transcript.tsx`,
  `RunLog.tsx`(대체될 수 있다), `RunPanel.tsx`(카드형 입력부로 재구성), `CommandPicker.tsx`
  위치, `index.css`, `icons.tsx`, `dockHeight.ts`, 새 컴포넌트(타임라인 투영·도구 행·마크다운).
- shared: 상태 이름 표(선택).
- core: 원칙적으로 없음. "다시 보내기"는 기존 `runs.resume`으로 된다.
- 의존성: 마크다운 라이브러리 하나(원시 HTML을 렌더하지 않는 것).
- e2e: 셀렉터(`.turn-user`, `.turn-answer`, `.dock-conv*`, `{name:'실행', exact:true}` 등)를
  지키거나 함께 고친다.

## 제약

- CLAUDE.md의 경계 셋, 색은 `:root` 토큰, 아이콘은 `icons.tsx`, 안내문 opacity 금지,
  장식 모션 금지(상태를 전하는 shimmer·스피너만, `prefers-reduced-motion` 존중).
- 초안 state를 언마운트될 수 있는 자식에 두지 않는다(설정 화면 FR-11과 같은 이유).
- 자동 확인은 여전히 목록 줄 클릭(`pick`)에만 건다. 턴을 강제로 여는 effect를 두지 않는다.
- 스키마·IPC는 바꾸지 않는다(이벤트를 넓히는 일은 `conversation-events`가 한다).

## 성공 기준

- 진행 중 턴에서 경과 시간·지금 도는 도구·흐르는 텍스트가 접힌 채로 보인다.
- 답변의 코드 블록·목록이 렌더되고 복사할 수 있다. `<script>`·`<img src=http…>`·
  `javascript:` 링크를 담은 답변이 아무것도 실행·로드·탐색하지 않는다(테스트로 고정).
- 긴 대화에서도 입력창이 바닥에 고정되고, 새 결과가 오면 따라 내려간다.
- 실행 중 턴을 입력부의 중지 버튼으로 멈출 수 있다. 예약이 입력창 위 칩으로 보인다.
- 대화 헤더 메뉴로 이름 바꾸기·끝내기를 할 수 있다.
- 라이트·다크 캡처로 확인한다(Playwright, 빌드된 앱).
- `pnpm test`·`pnpm typecheck`·`pnpm lint`·`pnpm test:e2e` 전부 통과.

## 이 기능이 아닌 것

탭 스트립·홈·통합 터미널·리뷰(diff) 패널, 권한 요청 카드, 여러 개 예약·방향 지시, 분기·
되돌리기, 대화 안 찾기 — 앞의 넷은 범위 밖이고 뒤의 것들은 설계 결정 변경이 필요한 별도 과제다.
