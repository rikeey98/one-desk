# Intent: 기간 동안 무엇을 했는지 여러 workspace에 걸쳐 한 번에 보기

- 상태: 결정 반영 (2026-10-07)

## 정해진 것 (2026-10-07, 사용자)

- **화면은 세 보기를 탭으로 모두 만든다** — 문서(안 A)·요일(안 B)·이슈 흐름(안 C). 시안:
  https://claude.ai/artifact/6bn58ES8XQwBP9k68VfV4E
- **진입점은 사이드바의 인박스 아래 "리포트"다.**
- **1차 범위에 "agent에게 다듬기"까지 넣는다** — 복사·메모로 저장에 더해.

## 문제

"지난주에 무엇을 했나"를 정리하려면 지금은 agent에게 시켜야 한다. MCP의 `list_issues`·`list_conversations`가
`since`·`until`을 받으므로(`docs/sdlc/timestamps/`) 한 workspace 안에서는 된다. 그러나 **workspace를 넘어서는
못 본다** — MCP 토큰이 workspace 하나에 묶여 있고, 전체 설계 §8("agent는 자신의 workspace 밖 데이터를 읽을
수도 수정할 수도 없다")이 그것을 약속한다. 일이 workspace 여러 개에 흩어져 있으면 workspace마다 따로 돌리고
결과를 손으로 합쳐야 한다.

게다가 매번 agent를 거치므로 느리고(수십 초), 토큰을 쓰고, 같은 기간을 두 번 물으면 답이 조금씩 다르다.
숫자(몇 개 만들고 몇 개 끝냈나)를 세는 일에 모델이 필요하지 않다.

## 원하는 결과

기간과 workspace를 고르면 **앱이 직접** 그 기간의 이슈·메모·대화를 모은 리포트를 곧바로 보여준다 — agent
없이, 같은 입력이면 같은 결과로. 그 리포트를 복사하거나 메모로 저장할 수 있고, 저장한 메모를 맥락에 담아
agent에게 "팀 공유용으로 다듬어 줘"를 시킬 수 있다.

**agent의 경계는 그대로다.** workspace를 넘는 데이터가 agent에게 가는 길은 사람이 리포트를 보고 메모로
저장해 맥락에 담는 것 하나뿐이다 — "필요한 맥락을 골라 넘긴다"는 앱의 원래 모양이다.

## 영향받는 것

- 사람: 여러 workspace(회사 일·개인 프로젝트 등)를 오가며 주간 회고·보고를 쓰는 사용자.
- 데이터: `issue`(`created_at`·`started_at`·`closed_at`·`updated_at`·`status`), `memo`(`created_at`·`updated_at`),
  `run`(대화 묶음 — `root_run_id`, 턴 시각, 상태, `issue_id`). **읽기만 한다 — 스키마 변경 없음.**
- 코드: `core/mcp/`의 기간 판정(`touchedIn`)·대화 요약(`summarizeConversations`)·시각(`toIso`·`parseBound`)을
  리포트와 함께 쓰게 된다. 두 곳이 "기간 안"을 다르게 정의하면 agent가 말하는 숫자와 화면 숫자가 갈린다.
- 화면: 사이드바(새 진입점), 메모(저장 대상).

## 제약

- **MCP 도구를 workspace 밖으로 넓히지 않는다** (전체 설계 §8). 이 기능은 MCP를 건드리지 않는다.
- 세 경계(`core/`는 electron 없음 · renderer는 core 없음 · IPC는 얇다)를 지킨다.
- **활동 기록이 없다** (timestamps spec §4가 범위 밖으로 뺐다). 이슈마다 마지막 `startedAt`·`closedAt`만 있으므로
  기간 안에 done → 다시 열림이 있었다면 "완료"로 잡히지 않는다. 이 기능 때문에 활동 기록을 새로 만들지는 않는다.
- `updatedAt`은 agent가 MCP로 고쳐도 오른다 — "손댄 이슈"는 누가 손댔는지 모른다.
- 리포트는 신뢰할 수 없는 입력(agent의 답·이슈 본문)을 품는다. 화면에 그릴 때는 기존 `Markdown`의 규칙을 따른다.

## 미해결 질문

- 리포트를 메모로 저장하면 어느 workspace에 들어가는가.
  (가정: **지금 고른 workspace** — 리포트 전용 workspace를 강제하지 않는다)
- 주의 시작은 월요일인가. (가정: **월요일**, 기간 프리셋은 이번 주·지난주·지난 7일·직접 지정)
- 대화의 "걸린 시간"을 리포트에 싣는가 — 실행 시간 합은 사람이 일한 시간이 아니다.
  (가정: **싣되 "agent 실행 시간"이라고 부른다**)
